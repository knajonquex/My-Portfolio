# Ankan Bandyopadhyay — Cybersecurity Portfolio

A responsive, static portfolio site built from the supplied CV.

## Run locally
Open `index.html` directly, or run:
python -m http.server 8000

Then visit http://localhost:8000

## Deploy
Upload the folder to GitHub Pages, Netlify, Vercel (static), Cloudflare Pages, or any standard web host.

## Notes
- Content is based on the supplied CV.
- External profile links point to the GitHub, LinkedIn and TryHackMe URLs listed in the CV.
- Google Fonts are loaded remotely; the page otherwise has no framework/runtime dependency.
